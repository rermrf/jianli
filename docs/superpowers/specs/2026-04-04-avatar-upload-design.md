# 头像上传与展示打通设计

## 概述

在当前第二阶段真实后端与真实前端联通的基础上，新增头像上传能力，并打通编辑页、展示页、打印页的头像展示链路。

本次改动的目标是：
- 编辑页支持选择图片、本地预览、裁剪并上传头像
- 后端接收头像文件并返回可访问 URL
- 简历数据保存 `profile.avatarUrl`
- 展示页和打印页统一读取 `profile.avatarUrl` 渲染真实头像

## 范围

### 包含

- 简历数据结构新增 `profile.avatarUrl`
- 后端新增头像上传接口
- 后端新增头像文件静态访问路径
- 编辑页新增头像上传与裁剪交互
- 展示页显示真实头像
- 打印页显示真实头像

### 不包含

- 多头像管理
- 旧头像文件自动清理
- 滤镜、美颜、背景抠图
- 非正方形头像裁剪模式

## 推荐方案

采用“前端裁剪 + 后端存储最终结果 + 简历 JSON 只保存头像 URL”的方案。

原因：
- 前端可以提供即时预览和裁剪交互
- 后端只管理最终文件，职责清晰
- 展示页与打印页只依赖一个稳定字段 `avatarUrl`
- 后续若要换存储介质或接对象存储，只需替换上传接口实现

## 数据结构

在简历 JSON 中新增字段：

```json
{
  "profile": {
    "avatarUrl": "/uploads/avatars/xxx.png"
  }
}
```

约束：
- 没有头像时字段可为空字符串或省略
- 前端显示层应优先显示 `avatarUrl`，否则退回默认占位头像

## 后端设计

### 上传接口

新增：
- `POST /api/upload/avatar`

请求：
- `multipart/form-data`
- 表单字段名建议为 `file`

响应：

```json
{ "code": 0, "data": { "url": "/uploads/avatars/<generated>.png" } }
```

### 鉴权

上传接口需走现有后台鉴权，与编辑页权限一致。

### 文件存储

头像文件保存到：
- `./data/uploads/avatars/`

要求：
- 启动或上传时自动创建目录
- 文件名使用唯一值生成，避免覆盖
- 不直接使用原始文件名作为最终文件名

### 文件访问

后端需提供静态访问路径：
- `/uploads/avatars/*`

这样前端保存的 `avatarUrl` 可以直接用于 `<img src>`。

### 服务端校验

至少校验：
- 文件存在
- 文件类型是图片
- 文件大小不超过约定上限

第一版建议限制在 5MB 左右。

## 前端设计

### 编辑页

编辑页新增头像编辑区，包含：
- 当前头像预览
- 选择图片按钮
- 重新上传按钮
- 裁剪确认按钮
- 取消操作

### 裁剪流程

流程如下：
1. 用户选择本地图片
2. 前端生成本地预览
3. 用户在前端进行 `1:1` 裁剪
4. 前端导出裁剪后的正方形结果图
5. 上传裁剪结果到后端
6. 后端返回 `avatarUrl`
7. 前端把 `avatarUrl` 写入当前简历草稿
8. 继续走现有保存简历流程，把头像 URL 保存进 `/api/resume`

### 裁剪边界

本次仅支持：
- 固定 `1:1` 比例
- 拖拽选区
- 缩放
- 确认 / 取消

不做旋转、不做滤镜。

### 展示页与打印页

- 展示页使用 `profile.avatarUrl` 替换当前占位头像
- 打印页同样使用 `profile.avatarUrl`
- 打印页应限制头像尺寸和容器大小，避免异常图片比例破坏版式

## 错误处理

### 前端

- 非图片文件：选择后立即提示，不进入上传
- 文件过大：前端先提示
- 上传失败：保留原头像，提示失败
- 裁剪取消：不改动当前头像

### 后端

- 缺文件：返回 400
- 文件类型不合法：返回 400
- 文件过大：返回 400
- 保存失败：返回 500

## 测试边界

### 后端

至少覆盖：
- 上传接口鉴权
- 非图片文件拦截
- 上传成功返回 URL
- 头像目录自动创建

### 前端

至少覆盖：
- 选择图片后的预览状态
- 上传成功后把 `avatarUrl` 写入简历保存流程
- 展示页有 `avatarUrl` 时显示真实头像
- 打印页有 `avatarUrl` 时显示真实头像

### 人工联调

需手工验证：
- 编辑页上传头像后保存成功
- 展示页刷新后看到新头像
- 打印页刷新后看到新头像
- 图片 URL 可直接访问

## 验收标准

满足以下条件视为完成：
- 编辑页可上传并裁剪头像
- 后端能保存头像文件并返回稳定 URL
- 简历保存后 `profile.avatarUrl` 持久化成功
- 展示页显示真实头像
- 打印页显示真实头像
- 前后端测试通过
